## System Requirements & Deployment

**Supported OS:** Windows Server 2008 R2 → 2025 (recommended 2019/2022/2025), Windows 10/11.  
**Recommended Hardware:** 8+ cores, 16 GB RAM, 100 GB disk (dedicated server preferred).  
**Database:** Bundled PostgreSQL or Microsoft SQL Server.

### Silent Installation (MSI)

<pre><code>msiexec /i "ADAuditPlus.msi" /qn /norestart</code></pre>

**Custom directory example:**

<pre><code>msiexec /i "ADAuditPlus.msi" INSTALLLOCATION="D:\ManageEngine\ADAuditPlus" /qn /norestart</code></pre>

Supports enterprise deployment via MSI, GPO, and SCCM. Agent MSI packages available for distributed collection.
